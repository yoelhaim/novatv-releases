# Nova TV Pro — downloads

Android apps for phones and Android TV boxes. Download them from the
[latest release](https://github.com/yoelhaim/novatv-releases/releases/latest).

Install both, in this order:

1. **Nova Player** (needed to play videos): [NovaPlayer.apk](https://github.com/yoelhaim/novatv-releases/releases/latest/download/NovaPlayer.apk)
2. **Nova TV Pro**: [NovaTVPro.apk](https://github.com/yoelhaim/novatv-releases/releases/latest/download/NovaTVPro.apk)

## On a TV box

1. Install **Downloader** (by AFTVnews) from the TV's Play Store.
2. Open it, enter the code or the link you were given, and press **Go**.
3. Install **Nova Player** first, then **Nova TV Pro**. If asked, allow Downloader to install unknown apps.
4. Open **Nova TV Pro** from the TV's Apps row.
